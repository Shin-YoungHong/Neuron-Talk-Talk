## 🏆 수상 경력
* **Winter AI Bootcamp Excellence Award (우수상)** 수상
* 시상금 100만 원 수령

## 🛠️ 내가 담당한 역할
* **LLM-TTS 연동부 개발:** Large Language Model(LLM)의 텍스트 응답을 음성 합성 엔진(TTS)으로 실시간 전달하는 파이프라인 설계 및 구현 담당.
* **시나리오 병합:** 전체 시스템의 시나리오 흐름을 제어하는 `merge-sinario` 로직 최적화.

## 📁 주요 포함 자료
* **소스 코드:** Python 기반의 AI 모듈 연동 코드
* **발표 자료:** 프로젝트 전체 구조 및 기술 스택이 담긴 최종 발표 PDF
* **증빙 자료:** AI 부트캠프 상장 사진
